# SonarBeat

スマートフォン/PCのスピーカーから発した超音波（連続波）の反射をマイクで受信し、ドップラー効果による位相変化から**呼吸数(BPM)を非接触で推定する**実験的なWebアプリです。

## 概要

- ファイル: `index.html`（外部ライブラリ不要、Google Fontsのみ利用）
- 学術研究分野で使われる「音響センシングによる非接触バイタルモニタリング」の手法（連続波ドップラー + I/Q復調）を模した実装
- 30秒間の計測で呼吸波形・BPM値・スペクトルなどを可視化

## 主な機能

| 機能 | 説明 |
|---|---|
| BPM推定 | 30秒間の計測から呼吸数(回/分)を算出して表示 |
| 呼吸ゾーン表示 | 6〜42+ bpmの目盛りで現在値の位置を色分け表示（正常/やや異常/警告） |
| 送信周波数調整 | 13kHz〜22kHzの範囲でスライダー/プリセットにより選択可能 |
| 布団越し計測モード | 13〜17kHzを選ぶと、布団による減衰を見込んだ低め周波数用のヒントを表示 |
| 呼吸波形タブ | 位相アンラップ後のなめらかな呼吸波形を表示 |
| I/Qタブ | 復調後のI/Q時系列波形とI/Qプレーン(リサージュ図形風)を表示 |
| スペクトラムタブ | 呼吸帯域(0.1〜0.7Hz相当)のFFT結果を棒グラフで表示し、推定BPMの位置を点線でマーク |
| フェーズ表示 | 「信号収集→FFT解析→最終結果」の3段階をプログレスバーとチップで表示 |
| ログ | 開始/停止/エラー/周波数変更などのイベントをタイムスタンプ付きで記録 |

## 使い方

1. ブラウザで `index.html` を開く
2. 送信周波数を選ぶ（布団越しなら13〜17kHz、布団なしなら18〜22kHzが目安）
3. 「計測を開始する」を押す（マイクのアクセス許可が必要）
4. 表示された位置にスマートフォン/PCを置き、30秒間なるべく動かない
5. 計測完了後、BPM値と各種グラフを確認する

## 内部の処理（DSPパイプライン）

1. **CW送信**: 指定周波数の正弦波（可聴域外）をオシレーターで出し続ける
2. **収音**: `echoCancellation`/`noiseSuppression`/`autoGainControl` をすべてOFFにしたマイク入力を取得
3. **ダウンサンプリング**: 48kHz→約480Hzへ間引き平均
4. **直交復調(I/Q復調)**: 受信信号に送信周波数のcos/-sinを乗算し、ローパスフィルタ(2次)で高周波成分を除去
5. **位相アンラップ**: `atan2(Q, I)` で位相を求め、±πの折り返しを補正して連続的な波形に変換
6. **メディアンフィルタ**: 適応的メディアンフィルタで振幅変動を、通常のメディアンフィルタで位相波形の平滑化を行う
7. **FFT**: 自前実装のFFTで0.1〜0.7Hz（6〜42回/分に相当）の帯域を解析し、最もパワーの大きい周波数をBPMとして採用

## 精度についての注意（重要）

**このアプリで安定して信頼できる精度は出ていません。** 実装・利用にあたって次の点を理解しておく必要があります。

- 呼吸によるドップラー変位はごくわずかで、体動・環境ノイズ・スマートフォンの位置ずれ・空調の風などによる位相変化と区別がつきにくく、誤検出が起きやすい
- 30秒という短い観測窓では、FFTの周波数分解能が粗く(帯域幅0.1〜0.7Hzに対し)、BPM推定値が数回/分単位でぶれやすい
- 布団越し(13〜17kHz)では信号減衰が大きく、布団なし条件よりさらに精度が落ちる
- スマホ内蔵スピーカー/マイクの周波数特性や配置、体格・服装の違いによって結果は大きくばらつく
- 医療機器としての較正・検証は行われておらず、実際の呼吸数と数bpm以上ずれることが珍しくない

つまり、実験・学習目的のデモ、あるいは大まかな傾向把握のツールとして扱うべきで、**健康状態の判断や医療的な用途（無呼吸の検知、乳幼児の見守りなど）に単独で使うべきではありません。** 精度を上げたい場合は、観測時間を延ばす、複数回計測して平均を取る、体動が少ない条件で計測する、といった工夫が必要です。

## 使用上の注意（プライバシー・同意）

- この仕組みは対象者に気づかれにくい周波数帯を使うため、**必ず計測対象者本人の同意を得た上で使用してください。** 同居人やパートナーなど他者を無断で計測することは、本人が気づかないままバイタル情報を取得する行為になり、プライバシー上の問題があります。
- 「布団越し計測モード」は布団を隔てた状態での計測を想定した機能ですが、これも同意のある自己計測（体調管理など）を目的とした利用にとどめてください。

## 注意点・制限事項

- マイクのアクセス許可が必要です
- 13kHz〜22kHzは人によっては聞こえる/不快に感じる場合があります。特に若年層は可聴域が広い傾向があるため配慮してください
- 計測結果はブラウザを閉じると保存されません
- スマートフォン内蔵スピーカー・マイクの性能によって出力/収録できる周波数帯域が制限される場合があります

## カスタマイズのヒント

- `TOTAL_SECS`（計測時間、既定30秒）を伸ばすとFFTの周波数分解能が上がり、精度改善が期待できる
- `FREQ_INFO` オブジェクトを編集すれば、周波数ごとのヒント文言やプリセットを追加・変更できる
- `estimateBPM()` 内の探索帯域（0.1〜0.7Hz）を調整すれば、対象とする呼吸数の範囲を変更できる
