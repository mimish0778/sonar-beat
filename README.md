# SonarBeat

スマホや PC のスピーカーから聞こえにくい高周波を出し、その反射をマイクで拾って、呼吸数（回/分）を非接触で推定する実験的な Web アプリです。

呼吸で胸が動くと反射音の位相がわずかに変わるので、それを 30 秒間追いかけて呼吸の周期を求めます。音響センシングによる非接触バイタル計測の論文でよく使われる「連続波ドップラー + I/Q 復調」をブラウザ上で真似したものです。`index.html` 1 ファイルで動きます。

> **医療用途には使えません。** 精度はまだ安定しておらず、実際の呼吸数と数 bpm 以上ずれることもよくあります。学習・実験用のデモとして扱ってください。

## 使い方

1. `index.html` をブラウザで開く
2. 送信周波数を選ぶ（13〜22kHz）
   - 布団なし: 18〜22kHz（標準は 20kHz）
   - 布団越し: 13〜17kHz（低い周波数のほうが布団で減衰しにくいため）
3. 「計測を開始する」を押す（マイクの許可が必要です）
4. 端末を胸の近くに置いて、30 秒間なるべく動かずに待つ

最初の 15 秒は信号の収集だけで、15 秒を過ぎると推定値が出始め、30 秒で確定します。

結果は 3 つのタブで見られます。

- **呼吸波形** — 反射音の位相から取り出した呼吸の波
- **I/Q** — 復調した I/Q 信号の時系列と I/Q 平面
- **スペクトラム** — 呼吸帯域の FFT。推定した BPM の位置に線が入ります

BPM は 12〜20 を正常範囲として色分けしています。

## しくみ

1. 選んだ周波数のサイン波をスピーカーから出し続ける
2. マイク入力を、エコーキャンセル・ノイズ抑制・自動ゲイン調整をすべてオフにして取り込む
3. 48kHz を 100 サンプルずつ平均して 480Hz に間引く
4. 送信周波数の cos / −sin を掛けて I/Q に分け、1Hz のローパスフィルタ（2 次バターワース）を通す
5. 窓ごとに中央値を引いて、壁や家具などの静止した反射を取り除く
6. `atan2(Q, I)` で位相を求めてアンラップし、メディアンフィルタでならす
7. FFT で 0.1〜0.7Hz（6〜42 回/分）の中からいちばん強い周波数を BPM とする

## 精度について

いまのところ、安定して信頼できる精度は出ていません。主な理由は次のとおりです。

- 呼吸による位相変化はとても小さく、体の動き、端末のずれ、エアコンの風などと区別しにくい
- 30 秒の観測では FFT の分解能が約 2 bpm しかなく、推定値が飛びやすい（15 秒時点では約 4 bpm）
- 布団越しだと信号が大きく減衰する
- スピーカー・マイクの性能、置き方、体格や服装で結果が大きく変わる

### 既知の問題

コードを読み直して気づいた点です。精度が出ない原因の一部になっている可能性があります。

- **復調の前に間引いている。** 手順 3 の 100 サンプル平均は、20kHz 前後の搬送波を約 40dB 弱めてしまいます。一方で広帯域のノイズは 20dB 程度しか落ちず、480Hz に折り返して入ってくるため、復調前の時点で S/N がかなり悪くなっています。48kHz のまま I/Q 復調してから間引くほうが筋が良いはずです。
- **18kHz では Q がゼロになる。** 18kHz は 480Hz の倍数のちょうど半分なので、間引き後の世界では −sin がすべて 0 になり、位相が取れません。スライダーで 18kHz を選ぶと計測が実質的に成り立ちません。
- AudioContext のサンプルレートは 48kHz を前提に固定しています。

## 使うときの注意

- **計測される本人の同意を必ず取ってください。** 聞こえにくい周波数を使うので、相手に気づかれずに計測できてしまいます。同居人などを無断で計測するのはやめてください。布団越しモードも、自分の体調管理など同意のある使い方に限ってください。
- 13〜22kHz は、若い人やペットには聞こえたり不快に感じたりすることがあります。
- 計測結果は保存されません。
